# Known Version Strings

These are examples of strings returned in the operating system field in response to the `ping` message on the NS public bus. The typical syntax is <OS>/<version>, with Companion releases up to 8.3.2 returning only the version number. Pre-release builds of Companion 8.4.0 had a particularly strange numbering scheme designed to ensure that versions would be sorted between 8.3.11 and 8.4.0 when evaluated numerically.
